# What to Test - Hoot Beta

## Welcome to Hoot Beta Testing! 🦉

Thank you for helping us test Hoot! Please focus on testing the following features:

### 🔐 Authentication & Setup
- Sign in with Apple (should work smoothly)
- Create a unique username
- Set your display name
- Verify login persists after closing the app

### 👥 Friends & Connections
- Add friends by scanning QR codes
- Send and receive friend requests
- Accept/decline friend requests
- Cancel pending friend requests
- Verify friend list updates in real-time

### 💬 Messaging (Hoots)
- Send Hoots to individual friends
- Receive Hoots and view them
- Check that push notifications arrive when app is closed
- Verify notifications only show for your account (not old test accounts)
- Test message delivery and viewing

### 👨‍👩‍👧‍👦 Groups
- Create groups with friends
- Send Hoots to groups
- View group activity
- Manage group members

### ⚙️ Settings
- Update your display name
- Set default Hoot text
- Sign out (should clear all data)
- Delete account (should remove all data and notify groups)

### 🔔 Notifications
- Receive push notifications when app is closed
- Verify notifications are only for your account
- Test notification navigation to messages
- Check that old notifications are cleared on sign-in

### 🐛 General Testing
- App should work completely standalone (no server needed)
- Test on different network conditions
- Verify app doesn't crash
- Check that all features work as expected
- Report any bugs or issues you encounter

### 📝 What to Report
- Any crashes or freezes
- Features that don't work as expected
- Issues with notifications
- Problems with friend requests
- Any confusing UI or unclear instructions

Thank you for your help! 🎉
